# Sources and verification policy

## Main CEFR vocabulary reference
1. Oxford Learner's Dictionaries — Oxford 3000 and Oxford 5000:
   https://www.oxfordlearnersdictionaries.com/about/wordlists/oxford3000-5000
2. Oxford 3000 by CEFR level (PDF):
   https://www.oxfordlearnersdictionaries.com/external/pdf/wordlists/oxford-3000-5000/The_Oxford_3000_by_CEFR_level.pdf
3. English Vocabulary Profile:
   https://englishprofile.org/

Oxford states that the Oxford 3000 contains 3,000 core words aligned to A1–B2. Oxford University Press has described the revised list's approximate level profile as 900 A1, 800 A2, 700 B1 and 600 B2 words. These figures describe that particular Oxford list; they are not CEFR-mandated vocabulary quotas.

## Priority pronunciation and meaning sources
1. Oxford Learner's Dictionaries — British pronunciation and definitions: https://www.oxfordlearnersdictionaries.com/
2. Cambridge Dictionary — British pronunciation, definitions and usage: https://dictionary.cambridge.org/
3. Collins English Dictionary: https://www.collinsdictionary.com/
4. Longman Dictionary of Contemporary English: https://www.ldoceonline.com/

## Record-level evidence
For every published entry, record at least one source that directly supports the UK pronunciation and core meaning. Use additional sources for important multiple senses, disputed level assignment or pronunciation variants.

Do not invent source URLs, IPA, CEFR labels or dictionary confirmations. If a source cannot be checked, set verification_status to needs_review and explain the gap in notes.

## CEFR levels
The CEFR describes language proficiency and does not prescribe a fixed number of vocabulary items for each level. A0/Pre-A1 is an editorial foundation supplement, not an official CEFR level. For A1–B2, use Oxford's level labels as the primary classification for the Oxford 3000 core list. Use English Vocabulary Profile as a secondary reference, particularly when senses, parts of speech or uses have different levels. Never infer a CEFR level solely from perceived difficulty.

## UK pronunciation
Target contemporary Standard Southern British English (SSBE). Preserve lexical stress and vowel length. Distinguish UK forms from US forms. Where reputable sources show more than one UK pronunciation, record the selected form and note the variant.

## Copyright and data handling
Use sources to verify facts, not to reproduce proprietary dictionary definitions or example sentences. Write original example sentences and Ukrainian translations.
